# 具身智能科研雷达

面向**科研选题与方法理解**的本地研究台。Python 3.9+，无需安装第三方依赖或付费 API。


> 最新产品规则：每篇前台论文先完成GPT/会话代理精读、证据检查和技术增量卡片，再自动展示。新论文自动进入后台候选；用户无需逐篇选择或先人工确认。自动精读在专用会话运行，每3小时检查一次，每轮40分钟内最多完整精读两项，已完成多轮。当前数量以后台及内容manifest为准。详见docs/automatic-reading.md。

## 启动

在项目目录运行：

```sh
python3 run.py
```

打开 http://127.0.0.1:8765 。macOS 双击 **启动研究台.command** 会打开研究台；服务未运行时安装当前用户的登录常驻服务，无需保留终端窗口。手动运行命令时可用 Ctrl+C 结束；已启用常驻时请先停用或使用其他端口。

如端口占用，运行 `python3 run.py --port 8766`。

## 已实现

- **精读队列**：从前沿详情或全文证据页加入任务；后台自动准备原文，失败最多3次有界重试；取消、重新排队、服务重启恢复、代理领取/续租/提交和待核查状态均已实现。网页与iOS可操作，队列纳入备份。当前已配置本机会话自动精读，任务按后台安排接手。见 [使用说明](docs/reading-queue/README.md)。

- **前沿动态（默认首页）**：按具体研究增量展示日期、新改动、对照、作者证据和边界；首页先给重点概览，再进入详情。重点、全部更新、稍后读、已略过、时间与方向筛选均可用。VLA 等概念导读移到“方法背景”。
- **论文精读**：搜索、筛选、收藏、笔记与来源历史；新增 arXiv 全文提取、版本固定、按章节/PDF 页码检索与引用。可选模型解读每条附引文，引用不匹配时拒绝发布。
- **技术地图**：八个方向、研究问题、主题联系、关联工作的时间顺序。
- **选题池**：问题观察、证据与相关工作、待验证假设、最小实验；可创建、编辑、变更状态、归档和删除。
- **产业观察**：机构研究与模型、工具发布；关联原始来源。
- **信息源管理**：开关、检查时间、错误信息、返回条数。
- **更新**：首次使用时采集；运行期间默认每 180 分钟检查，可调整或关闭，也可手动检查。
- **备份**：导出 ZIP，包含 JSON 文献库、收藏/笔记 Markdown、选题 Markdown 和偏好设置。

## 信息源

| 来源 | 方式 |
| --- | --- |
| arXiv 机器人学习 | 自动，API 失败回退 cs.RO RSS |
| LeRobot 官方版本 | 自动，GitHub Releases API / 官方 Atom 订阅 |
| Isaac Lab 官方版本 | 自动，GitHub Releases API / 官方 Atom 订阅 |
| LeRobot 官方模型与数据集 | 自动，Hugging Face，固定提交的完整卡片 |

| CoRL、InternRobotics | 手动原始入口，尚未自动采集 |

公开源可能有网络或结构变化；失败时保留已有内容并显示原因，不将失败冒充为“没有新论文”。同一来源一分钟内不重复请求，使用有界响应和超时。

## 数据在哪里

当前 Mac 的数据实际位于 `~/Library/Application Support/ResearchRadar/Data`，项目 `data` 是指向它的符号链接。后台运行副本位于同级 `Runtime`，避免 macOS 对桌面目录的后台访问限制。

- `data/radar.sqlite3`：文献、收藏、笔记、选题、偏好与检查记录。
- `data/notes/`：保存笔记或收藏时同步写入的 Markdown 文件。
- `data/ideas/`：选题 Markdown 文件。

采集更新不会覆盖个人笔记、收藏或阅读进度。所有个人内容保存在本机，不发送给外部模型。可复制实际的 `Data` 目录备份（建议先停止服务，不要只复制符号链接），或使用网页中的 ZIP 导出。ZIP 也保留已提取全文片段和模型解读；原始 HTML/PDF 缓存可重新下载。

## 内容与判断

初始化包含七条具体研究增量的公开快照、五条按需背景导读和六篇**历史基础阅读卡**。日期与核对层级明确标注，不会把旧资料重新标成当天新闻。已核查原始论文元数据与摘要；导读不代表全文分析或代码复现。新采集内容保留原始摘要、发布说明或模型入口，主题由关键词分类。

首页按理解方法与科研价值组织编辑导读，核对日期与来源版本明确展示；关联新资料仅作为进一步阅读候选，不会因更新时间变成已核实的重要突破。论文推荐 API 仍可按关注主题、近期更新、论文类型和阅读进度排序。不使用伪造的引用量、影响分或能力分。模型修改时间只是可用性信号；候选问题始终需要相关工作检索与实验验证。

精读页提供个人笔记与分析程度标记；“全文分析”“代码核查”由用户在完成阅读后明确记录。

## 当前边界

- 普通命令仅本机访问；校园网模式使用 --lan，并要求远程设备输入访问码。
- 自动更新依赖服务运行，电脑睡眠或服务退出期间不会执行。
- 已接入按需全文提取、用户登录常驻与手机草稿同步；已提供临时公网 HTTPS 通道；尚未提供独立云端托管、邮件提醒与系统推送。
- 模型服务尚未配置，自动解读按钮保持禁用。当前可直接使用原文证据阅读；模型建议始终需要研究者核查，不宣称研究空白。

## 手机与校园网访问

双击启动脚本默认启用校园网模式，也可以运行 python3 run.py --lan。访问 http://127.0.0.1:8765/pair 可查看当前 HTTPS 地址、同网地址、二维码与访问码。访问码保存在本机 data/access-code.txt，不包含在二维码中。手机输入后可以读取和保存同一套笔记。

Mac 需保持开机并运行服务；校园网若开启设备隔离，同网账号也不保证可以互通。新增 Bonjour 自动发现及 .local 名称，减少 IP 变化影响；若不能解析，可使用配对页中的当前 IP。网页会话在服务重启后需要登录；原生 App 可使用钥匙串中的访问码重新登录。

## 本轮新增与运行管理

- iPhone 首次使用引导：发现研究台、扫描或粘贴配对链接、选择先离线阅读；首次离线草稿在第一次连接时带入同步队列，并检查冲突。
- 前台自动重连采用有限重试，连接失败通过离线状态展示，避免每次唤醒都弹窗；信息源检查期间显示进行状态，完成后刷新。
- 全文证据页：论文详情进入“全文证据精读”；准备后按英文关键词检索、回到原文、引用到笔记。原生端缓存全文，支持离线查看。
- 提取优先使用 arXiv HTML，回退 PDFKit；PDF有界流式下载，无文字层页面尝试Apple Vision本机OCR。识别仍有缺口时不把准备标为完整；图片和公式需要回原文核对。首次构建文本工具运行 `scripts/build_tools.sh`（Mac / Xcode）。
- 按需模型解读仅在服务进程配置 `OPENAI_API_KEY` 和 `RADAR_READING_MODEL` 后可用，当前未配置。只传公开论文片段，`store:false`，不传个人笔记。模型输入上限、覆盖片段数和出处均显示；引文匹配只检查文字，不保证推理正确。当前实现对应 OpenAI Responses API，其他模型提供方尚未实现。

管理当前用户的常驻服务：

```sh
python3 scripts/manage_service.py install  # 安装/更新运行副本并重启
python3 scripts/manage_service.py status
python3 scripts/manage_service.py remove   # 停止常驻，保留全部数据
```

服务随用户登录启动；Mac 睡眠或关机期间仍不能采集。更新项目代码后重新执行 install。日志在 `data/logs/`。校园网隔离与离开校园后的访问可使用单独的 HTTPS 通道，配置与当前限制见 [公网访问](docs/remote-access.md)。

## 前沿增量与背景资料

默认入口顺序为“具体新进展 → 改动对照与证据 → 可选原文/代码/全文笔记”。桌面默认展开一条进展，手机列表直接给增量与关键证据。不会默认解释 VLA 是什么。

- `content/frontier.json`：已核对的逐篇增量解读，含明确的对照做法、本次改动、证据、边界、研究问题、版本链接和核对日期。七条编辑草稿中当前仅RAFT已完成全文精读，只有它进入前台；作者结果未复现。
- 自动采集资料进入后台候选；未完成精读的新条目不进入前台。只有相符的论文版本才使用对应解读。新版本出现时，旧解读不会套到新版上。
- “已了解 / 稍后读 / 略过”是进展处理状态，与论文“在读 / 已读”、收藏和笔记独立；Mac 与 App 共用队列并核查冲突，App 可离线排队。稍后读与已略过不受 7 天窗口限制。
- 默认显示近 7 天；旧资料不会因为今天被查看而成为新进展。范围内无内容时显示空状态，可调整日期或显示已处理内容。
- `content/technologies.json`：基础方法背景，移到按需入口，不再承担前沿首页。

更新公开解读后运行 `python3 scripts/build_frontier_content.py` 更新 App 的离线快照；更新背景内容用 `python3 scripts/build_technology_content.py`。随后重新构建 App、更新服务运行副本。旧离线缓存仍能解码，未同步草稿保留。

交互原则与外部参考见 `PRODUCT.md`、`DESIGN.md`；设计检索结论见 `docs/design-research/references.md`。
